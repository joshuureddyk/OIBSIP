# Unemployment Analysis with Python

## Internship
Oasis Infobyte – Data Analytics Internship

## Task
Level 1 – Task 2: Unemployment Analysis with Python

## Objective
To analyze unemployment trends in India and understand regional differences and the impact of COVID-19 using Python.

## Tools Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

## Project Work
1. Dataset loading and inspection.
2. Missing value and duplicate removal.
3. Data cleaning and date conversion.
4. State-wise unemployment analysis.
5. Unemployment trend line chart.
6. Top 10 states bar chart.
7. Correlation heatmap.
8. Pre-COVID and post-COVID comparison.

## Conclusion
This project analyzes unemployment trends across Indian states using Python. Data cleaning and visualization techniques help identify regional differences and changes in unemployment during the COVID-19 period.
