# Google Play Store Analysis

## Project Overview
This project analyses Google Play Store applications to understand app categories, ratings, installations, pricing and content ratings using Python.

## Dataset
Google Play Store Apps dataset containing application details, reviews, ratings, installs, prices and categories.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
1. Data cleaning and preprocessing
2. Top 10 app categories
3. App rating distribution
4. Most installed applications
5. Free vs Paid app comparison
6. Average ratings by category
7. Content rating analysis

## Conclusion
The project provides insights into Google Play Store applications by analysing their popularity, ratings, categories and pricing. Data visualization helps understand user preferences and application trends.
