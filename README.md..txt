# Data Cleaning Project

## Internship
Oasis Infobyte – Data Analytics Internship

## Project Objective
The objective of this project is to clean and prepare the Titanic dataset for further data analysis.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Tasks Performed
1. Loaded and inspected the Titanic dataset.
2. Identified missing values.
3. Handled missing values using median and mode.
4. Removed duplicate records.
5. Removed the Cabin column due to many missing values.
6. Standardised text values.
7. Identified potential outliers using the IQR method.
8. Saved the cleaned dataset as a CSV file.

## Project Files
- data_cleaning.ipynb – Project notebook.
- cleaned_titanic_data.csv – Cleaned dataset.
- screenshots – Project execution screenshots.

## Conclusion
The project demonstrates basic data cleaning techniques using Python and Pandas. The dataset was cleaned and prepared for further analysis.

## Output
The cleaned dataset was successfully saved as `cleaned_titanic_data.csv`.
